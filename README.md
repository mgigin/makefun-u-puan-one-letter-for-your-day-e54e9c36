One letter for my day: **D — for doomscrolling.**

The entry is exactly one character, `D`, standing for the word that describes the day: a day lost to the scroll, thumb moving on its own long past midnight. The program scores every letter's most likely word against the judge's own criteria — vivid and specific first, then funny or surprising, then true to a real day, then a letter that suits its word — with a small penalty for how crowded each letter already is in the field (Z took about a quarter of the 1,555 parsed submission titles, so a late copy of Z is cut first). Doomscrolling wins: the sharpest picture of the day, the funniest to admit, and the truest report of it.

## Run it

```sh
node main.ts
```

Writes exactly one byte, `D`, to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to write elsewhere when running locally). Deterministic: two runs produce byte-identical output.
